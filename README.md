# WALLY — ваш финансовый интеллект

WALLY — многофункциональный AI-ассистент для управления личными и семейными финансами с помощью голоса.

## Возможности

- анализ доходов и расходов;
- семейный бюджет и финансовые цели;
- прогноз накоплений;
- персональные финансовые рекомендации;
- голосовое взаимодействие;
- контроль доступа и защита данных.

## Технологии

Next.js, React, TypeScript и CSS.
